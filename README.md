FindIt – Lost and Found Website

Project Description:
FindIt is a user-friendly Lost and Found website that helps people report, search for, and recover lost belongings.
Features:
- Home page with easy navigation.
- Browse available items.
- View lost and found items.
- Report lost belongings.
- Report found belongings.
- View submitted reports.

Technologies Used:
- HTML
- CSS
- Figma

Webpages:
1. Home – index.html
2. Browse – browse.html
3. Lost Items – lost.html
4. Found Items – found.html
5. My Reports – reports.html
